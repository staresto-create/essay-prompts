# 歷屆作文題目索引

學測與指定科目考試英文作文題目，83 至 115 學年度共 62 題。可依年度、文體、主題篩選。

## 內容

- 62 題：學測端 40 題（含補考、參考試卷、試辦考試、課綱參考試卷共 7 題），指考端 22 題（含補考 2 題）
- 27 題附原卷圖片，每張標明出處
- 9 題非正式考題以虛線框與標籤標明

## 檔案結構

| 路徑 | 內容 |
|---|---|
| `index.html` | 網站本體，無外部相依套件 |
| `data/prompts.json` | 62 題資料 |
| `images/` | 27 張圖，各有 WebP 與 PNG 兩種格式 |
| `sitemap.xml` | 給搜尋引擎的網址清單 |

## 資料欄位

`year` 學年度｜`exam` 考試場次｜`isOfficial` 是否正式考題｜`promptFormat` 原始題型欄
`hasImage` 是否附圖｜`genre` 文體｜`theme` 主題｜`prompt` 題目原文｜`images` 圖片檔名與尺寸
`source` 圖片出處｜`sameAs`、`reuseNote` 與其他年度重複時的註記
`promptSummary` 外部模型產出的圖片描述，未經查證，不在網站上顯示

## 版權

題目與圖片版權屬財團法人大學入學考試中心基金會所有，本站僅供非營利之教學與練習使用。
