# 歷屆作文題目索引

學測與指定科目考試英文作文題目，83 至 115 學年度共 63 題，另有 1 題本題庫自編的模擬題。可依年度、文體、主題篩選。

## 內容

- 63 題：學測端 41 題（含補考、參考試卷、試辦考試、課綱參考試卷共 8 題），指考端 22 題（含補考 2 題）
- 28 題附原卷圖片，每張標明出處
- 另有 1 題本題庫自編的模擬題（`SELF01`，`isSelfMade: true`，沒有年度）：題目文字與圖片都由本題庫自寫、自繪，圖中品牌全部虛構，不計入上面的 63 題
- 10 題非正式考題以虛線框與標籤標明

## 檔案結構

| 路徑 | 內容 |
|---|---|
| `index.html` | 網站本體，無外部相依套件 |
| `data/prompts.json` | 64 筆資料（63 題歷屆題目＋1 題自編題） |
| `images/` | 29 張圖（28 張原卷圖＋1 張自繪圖），各有 WebP 與 PNG 兩種格式 |
| `sitemap.xml` | 給搜尋引擎的網址清單 |

## 資料欄位

`year` 學年度｜`exam` 考試場次｜`isOfficial` 是否正式考題｜`promptFormat` 原始題型欄
`hasImage` 是否附圖｜`genre` 文體｜`theme` 主題｜`prompt` 題目原文｜`images` 圖片檔名與尺寸
`source` 圖片出處｜`sameAs`、`reuseNote` 與其他年度重複時的註記
`promptSummary` 外部模型產出的圖片描述，未經查證，不在網站上顯示

## 版權

歷屆題目與原卷圖片的版權屬於財團法人大學入學考試中心基金會，本題庫只用於非營利的教學與練習。自編題（`SELF01`）的題目與圖片由本題庫自行撰寫、繪製，不在此限。
